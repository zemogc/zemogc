<summary>Resumen en texto</summary>

**Zemog Gómez Tabares** — Founder & CEO de [ZemZysteM](https://zemzystem.com), empresa de tecnología en Colombia. Software Developer con más de 4 años de experiencia: diseño y construyo plataformas SaaS multi-tenant, señalización digital y automatización.

**Productos**

- **ZystemMedia** (en producción) — señalización digital: pantallas, contenido, playlists y programación para múltiples organizaciones.
- **Wayfinding** (en producción) — kioscos táctiles con rutas sobre plano y QR al celular.
- **Agent Office** (en producción) — agentes digitales con memoria, scoring determinista y aprobación humana.
- **Turnero** (en desarrollo) — SaaS white-label de gestión de turnos: kiosco, ventanilla y pantalla de sala en tiempo real.
- **Players** (en desarrollo) — un contrato de Player API para Android, Samsung Tizen y LG webOS.
- **NOC** (en desarrollo) — monitoreo propio de aplicativos y VPS con incidentes por umbral.

**Stack**

- Lenguajes: Python, TypeScript, JavaScript, Dart, PHP, C#, SQL.
- Backend: FastAPI, Django, DRF, SQLAlchemy, Alembic, Laravel. Frontend: React, Vite, PixiJS, Jinja2.
- Pantallas: Flutter, Android, Samsung Tizen, LG webOS. Datos: PostgreSQL, SQLite, Redis.
- Infraestructura: Docker, NGINX, Traefik, systemd, GitHub Actions.
- Arquitectura: hexagonal, monolito modular, multi-tenant, RBAC. Automatización: Rocketbot RPA.
